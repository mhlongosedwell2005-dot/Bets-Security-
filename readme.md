# 49s AR Dashboard Demo

Interactive 3D/WebXR dashboard built with `<model-viewer>`. Designed as a portfolio piece to show WebXR + 3D fallback handling.

**Live Demo:** https://mhlongosedwell2005-dot.github.io/49s-ar-dashboard-demo/

### Features
- 48-number data grid with bonus odds block
- Live data tickers + dropdown UI
- AR mode via WebXR on ARCore/ARKit devices
- 3D fallback for non-AR browsers/devices
- Device compatibility note baked into UI

### Tech Stack
HTML, CSS, JavaScript, Google `<model-viewer>`, WebXR

### Device Support
3D View works on all devices. AR button auto-activates on supported phones. Tested 3D fallback on Samsung A05.

*Note: This is a visual demo only. No real data or transactions.*
